Краткая выжимка контекста:

Создать высокопроизводительную систему визуализации графа на React-Konva с:

Тысячами нод (Node) и связей (Link)
Плавным перетаскиванием нод и камеры
Виртуализацией - рендерить только видимые элементы

Нестандартные решения
1. Подписочная система вместо useState
Почему: Ноды обновляются 60 раз в секунду при drag
Решение: Каждый LinkView подписывается на изменения конкретных нод - source & view
Результат: Нет массовых ререндеров всего графа

2. Grid-виртуализация
Проблема: Проверять каждую ноду на видимость при перемещении области видимости - O(n)
Решение: Делим канвас на grid ячейки (100x100px)
Логика: Ноды подписываются на свою grid-ячейку, ячейка уведомляет их о видимости
Сложность: O(количество_ячеек_в_viewport) вместо O(количество_нод)

3. Мутация состояния в подписках
Почему: Создание новых объектов для тысячи нод каждые 16ms тормозит

Решение: Мутируем флаг isVisible напрямую в объекте ноды

Важно: Мутируем только isVisible, остальные данные иммутабельные

Ключевые компоненты
Провайдер (CanvasContextProvider)
Содержит:

nodeIdToNodeRecord - все ноды

gridCellToNodeIds - индекс grid → ноды

subscribeToNode / subscribeToGrid - API подписки

onNodeChange - обновление ноды (при drag)

onZoomChange - обновление видимости (при скролле/зуме)

NodeView компонент
Подписывается на изменения своей ноды (координаты)

Подписывается на свою grid-ячейку (видимость)

Рендерит себя только если isVisible === true

LinkView компонент
Подписывается на две ноды (source и target)
Перерисовывает линию при изменении любой из нод

Производительность
onZoomChange: ~220 операций каждые 50ms (для 1920x1080, grid=100)
onNodeChange: O(1) + обновление подписчиков

Подписки: Каждая нода имеет 1-5 подписчиков (линки)

Что важно при реализации
Гарантировать существование структур подписок при инициализации
Аккуратная очистка при удалении нод из grid ячеек
Оптимизировать React рендеры через memo и правильные зависимости
Система оптимизирована для сценария: тысячи нод, частые обновления положения карты, редкие обновления данных, плавная анимация.
